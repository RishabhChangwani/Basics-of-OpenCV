# Hello World Script

This repository contains a simple Python script that prints 'Hello, World!' to the console.

## Files

- `hello_world.py`: The main script that prints 'Hello, World!'.
- `test_hello_world.py`: Unit tests for the `hello_world.py` script.

## Usage

To run the script, execute the following command:

```bash
python hello_world.py
```

## Testing

To run the unit tests, execute the following command:

```bash
python -m unittest test_hello_world.py
```

## Requirements

- Python 3.6+
